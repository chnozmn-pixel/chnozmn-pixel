## cozmen

I build small Windows tools that do one thing and stay out of the way.
Mostly C# desktop apps, with PowerShell and Python where a script fits better
than a program.

Two things I care about: a tool should run without an install ritual, and it
should never show a number it did not actually measure.

### Projects

| | |
|---|---|
| **[ScheduleOneTR](https://github.com/chnozmn-pixel/ScheduleOneTR)** | Turkish translation patch for Schedule I. ~9,700 lines of translated text, installed with a single line in PowerShell — it fetches the loader, builds itself and copies the files. The game's own data is never touched. |
| **[AudioHop](https://github.com/chnozmn-pixel/AudioHop)** | Switch the Windows sound device from the tray or an on-screen picker. |
| **[Cyfan](https://github.com/chnozmn-pixel/Cyfan)** | Merge, split and convert video. A small ffmpeg front end for Windows. |
| **[dns-boat](https://github.com/chnozmn-pixel/dns-boat)** | Automatic DNS switching for Windows, with optional DPI bypass. Tray app. |
| **[Wirecove](https://github.com/chnozmn-pixel/Wirecove)** | Shows what the programs on a machine are actually sending and receiving. Everything on screen is read from the machine itself. *In development.* |
